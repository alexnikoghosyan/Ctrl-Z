# Ctrl+Z — խաղի ուղեցույց

`Ctrl+Z`-ը պատմողական պիքսելային խաղ է տղայի, դեղին ռոբոտ-շան և ժամանակի միջով ճանապարհորդության մասին։ Առաջին գլուխը սկսվում է ննջարանում, հետո տանում է դեպի Չեռնոբիլի ատոմակայան՝ 1986 թվական, վթարից 5 րոպե առաջ։

## Գլուխ 1․ Կրիտիկական 5 րոպե

Տղան ու ռոբոտ-շունը բացում են հին գիրքը և տեղափոխվում Չեռնոբիլի ատոմակայան։ Շան համակարգերը կանխատեսում են, որ չորրորդ էներգաբլոկում վթարը սկսվելու է 5 րոպեից։ Միջանցքի մյուս ծայրում հերթապահ պահակը սկզբում կասկածում է տղայի խոսքերին, բայց տագնապի ազդանշաններին հավատալով՝ տալիս է անցագիրն ու կառավարման վահանակի կոդը՝ `VWRS`։ Հետհաշվարկը սկսվում է պահակի հետ խոսակցությունից հետո։

Կոդը մուտքագրելուց հետո վահանակը մերժում է այն։ Ռոբոտ-շունը նկատում է, որ `VWRS`-ը Կեսարի +3 ծածկագիր է․ յուրաքանչյուր տառ երեք քայլ առաջ է տեղափոխվել։ Խաղացողը պետք է տառերը երեք քայլ հետ տանի և ստանա `STOP` կոդը։ Մուտքը բացվելուց հետո վահանակի Մորզեի ազդանշանը՝ `.-. . -..`, հուշում է ընտրել կարմիր կոճակը։

Ճիշտ ընտրությունը կանխում է պայթյունը։ Սխալ կոճակը կամ ժամանակի սպառվելը պայթյուն է առաջացնում։ Պայթյունից հետո `Ctrl+Z`-ը հետ է տալիս 15 վայրկյան, իսկ `RESTART`-ը նորից սկսում է խաղը։

## Կառավարում

| Գործողություն | Կոճակ |
| --- | --- |
| Շարժվել | `A` / `D` կամ `←` / `→` |
| Փոխազդել, խոսել պահակի հետ, օգտագործել մահճակալը | `E` |
| Գիրքը թերթել կամ երկխոսությունը շարունակել | `←` / `→` կամ `E` |
| Պայթյունից հետո 15 վայրկյան հետ գնալ | `Ctrl+Z` |
| Սկսել նորից | `RESTART` կոճակ |

## Սկսել խաղը

1. Բացեք նախագիծը Godot **4.7 կամ ավելի նոր** տարբերակով՝ `project.godot` ֆայլից։
2. Գործարկեք հիմնական տեսարանը։
3. Ննջարանում մոտեցեք գրքին և սեղմեք `E`, որպեսզի սկսեք պատմությունը։
4. Մոտեցեք մահճակալին և սեղմեք `E`՝ Չեռնոբիլի գլուխ անցնելու համար։
5. Չեռնոբիլում հետևեք էկրանի հուշումներին, խոսեք պահակի հետ և գնացեք դեպի կառավարման վահանակը։

## Ձայներ և պատկերներ

Երաժշտությունն ու էֆեկտները կապված են խաղի գործողությունների հետ․

- գրքի բացում՝ `book_open.mp3`,
- քայլելիս՝ կրկնվող `footsteps.mp3`,
- Չեռնոբիլ անցնելիս՝ լույսի խափանման ձայն, իսկ փուլում՝ միջավայրային ձայն,
- վահանակի մոտ՝ ռադիոխշշոց, սխալ կոդի դեպքում՝ ռոբոտ-շան հաչոց,
- վերջին 10 վայրկյանին՝ մեկ վայրկյանը մեկ ազդանշան,
- սխալ կոճակի կամ ժամանակի սպառվելու դեպքում՝ հոսանքի գերբեռնվածության ձայն,
- առավոտյան տեսարանի անցման պահին՝ աքաղաղի կանչ։

Խաղի պատկերների և ձայների մի մասը վերցված է [HAYQ333/hevan-hack-club-project](https://github.com/HAYQ333/hevan-hack-club-project) նախագծից։ Ձայնային ֆայլերը պահվում են `Music/` պանակում, պատկերները՝ նախագծի արմատում և `Images/` պանակում։

## Տեխնիկական տեղեկություն

- Շարժիչ՝ Godot 4.7+
- Հիմնական տեսարան՝ `scene/intro.tscn`
- Խաղի տրամաբանություն՝ `scene/intro.gd`, կերպարի շարժում և ռոբոտ-շան հետևում՝ `scene/character_body_2d.gd`
- Պատմության երկխոսությունները, կոդի և Մորզեի հանելուկները գտնվում են հիմնական տեսարանի սցենարում։
